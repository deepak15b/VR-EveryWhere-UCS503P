**📅 Date:** August 21 – August 27, 2026

### 🛠️ Key Contributions & Decisions

- **👤 User Requirements:** Analyzed the requirements identified during Week 1 to determine the backend interactions required by the system.

- **🔐 Authentication Use Cases:** Identified **Register** and **Login** as important system use cases for managing user accounts.

- **🗄️ Backend Use Cases:** Identified backend-related functionality including:
  - Register / Login
  - Retrieve Destination Information
  - Manage Favorites
  - View Tour History

- **🔗 System Interaction:** Analyzed how the VR client would communicate with the backend to retrieve destination information and store user-related data.

- **📐 UML Use Case Diagram:** Contributed the backend and system-related use cases to the UML Use Case Diagram and helped establish their relationship with the primary **User** actor.

- **🗃️ Database Requirements:** Identified the main data entities required by the backend, including:
  - Users
  - Destinations
  - Favorites
  - Tour History

- **📊 Gantt Chart:** Added backend-related development activities to the project plan, including **Spring Boot setup, REST API development, PostgreSQL database design, authentication, and backend integration**.

- **🤝 Team Coordination:** Coordinated with the VR development work to ensure that backend tasks would support the requirements of the Unity application.
